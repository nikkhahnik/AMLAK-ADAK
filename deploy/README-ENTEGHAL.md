# انتقال amlakadak.ir از Netlify به هاست/سرور ایرانی

سایت کاملاً استاتیک است. محتوا و ظاهر در این انتقال هیچ تغییری نمی‌کند؛
همهٔ صفحه‌ها بایت‌به‌بایت همان چیزی هستند که الان آنلاین است.

---

## ۰) موقع خرید هاست این‌ها را بخواهید

| نیاز | چرا |
|---|---|
| فضا: حداقل ۱ گیگابایت | سایت + عکس‌ها حدود ۱۲۰ مگابایت است |
| پشتیبانی `.htaccess` (Apache یا LiteSpeed) | آدرس‌های تمیز و هدرهای امنیتی |
| PHP نسخهٔ ۸ یا بالاتر + افزونهٔ cURL | فقط برای پنل مدیریت |
| SSL رایگان (Let's Encrypt) | سایت باید روی HTTPS بماند |
| دسترسی FTP یا FTPS | برای انتشار خودکار از گیت‌هاب |

اگر هاست **فقط nginx** بود (مثلاً DirectAdmin با nginx)، فایل
`deploy/nginx-amlakadak.conf` را به پشتیبانی بدهید؛ معادل دقیق `.htaccess` است.

---

## ۱) آپلود سایت

۱. فایل `adak-site-for-host.zip` را در پنل هاست، داخل `public_html` آپلود و استخراج کنید.
۲. مطمئن شوید `.htaccess` و پوشهٔ `api` هم استخراج شده‌اند (بعضی پنل‌ها فایل‌های مخفی را نشان نمی‌دهند).

## ۲) تنظیم پنل مدیریت

۱. فایل `api/admin/config.sample.php` را کپی کنید به `api/admin/config.php`.
۲. داخلش این چهار مقدار را **خودتان** پر کنید:
   - `ADMIN_USER` و `ADMIN_PASSWORD` — همان نام کاربری و رمز فعلی پنل
   - `GITHUB_TOKEN` — توکن گیت‌هاب با دسترسی `Contents: Read and write` روی همین مخزن
   - `GITHUB_REPO` و `GITHUB_BRANCH` را دست نزنید
۳. فایل را ذخیره کنید. از طریق مرورگر قابل خواندن نیست (تست شده: ۴۰۳).

> رمز و توکن را هیچ‌جا برای من نفرستید؛ خودتان مستقیم روی هاست بگذارید.

## ۳) انتشار خودکار از گیت‌هاب

در گیت‌هاب → `Settings` → `Secrets and variables` → `Actions`:

**Secrets** (دکمهٔ New repository secret):
- `FTP_SERVER` — آدرس FTP هاست
- `FTP_USERNAME` — نام کاربری FTP
- `FTP_PASSWORD` — رمز FTP

**Variables** (تب کنارش):
- `FTP_DIR` — معمولاً `/public_html/`

از این به بعد هر تغییری که روی `main` برود، خودکار ساخته و روی هاست آپلود می‌شود —
دقیقاً همان کاری که Netlify می‌کرد، بدون هزینه.

## ۴) تست قبل از تغییر DNS (مهم)

قبل از اینکه دامنه را عوض کنید، سایت را روی هاست جدید تست کنید:

- اگر هاست آدرس موقت می‌دهد (مثل `amlakadak.ir.hostname.com`)، با همان باز کنید.
- یا روی کامپیوتر خودتان فایل hosts را موقتاً تغییر دهید.

این‌ها را چشمی چک کنید:
- صفحهٔ اصلی و منو
- `/p/adk-06` و بقیهٔ فایل‌ها (آدرس بدون `.html` باید کار کند)
- `/tour/adk-06/` — تور ۳۶۰ درجه
- لایت‌باکس عکس‌ها (کلیک روی عکس)
- `/admin/` — ورود و دیدن لیست فایل‌ها

## ۵) تغییر DNS

۱. در پنل ریجسترار دامنه، رکوردها را به هاست جدید ببرید
   (`A` به IP هاست، یا `NS` اگر هاست نیم‌سرور می‌دهد).
۲. **Netlify را حذف نکنید** تا DNS کامل پخش شود (۲ تا ۲۴ ساعت).
   تا آن موقع هر دو سرور همان سایت را نشان می‌دهند، پس قطعی نداریم.
۳. بعد از پخش DNS، در پنل هاست SSL رایگان (Let's Encrypt) را فعال کنید.
۴. تست کنید `http://amlakadak.ir` خودکار به `https://` برود.

## ۶) بعد از انتقال

- [ ] در سرچ کنسول گوگل، مالکیت را دوباره تأیید کنید
      (فایل `googlea1fc99ef7e650390.html` منتقل شده، پس باید خودکار بماند).
- [ ] `sitemap.xml` را دوباره در سرچ کنسول ثبت کنید.
- [ ] چند روز سایت را زیر نظر بگیرید، بعد سایت Netlify را پاک کنید.
- [ ] متغیر `git_huub_key` در Netlify را حذف کنید (بی‌استفاده است).

## اگر VPS خریدید (نه هاست اشتراکی)

۱. `deploy/nginx-amlakadak.conf` را در `/etc/nginx/sites-available/` بگذارید و
   به `sites-enabled/` لینک کنید.
۲. فایل‌های سایت در `/var/www/amlakadak`.
۳. `php-fpm` نصب باشد (برای پنل مدیریت).
۴. SSL با `certbot --nginx -d amlakadak.ir -d www.amlakadak.ir`.
۵. اگر nginx از خط‌های `listen [::]:...` خطا گرفت، سرور IPv6 ندارد؛ آن خط‌ها را حذف کنید.

## چه چیزی عوض شد و چه چیزی نشد

**عوض نشد:** تمام HTML، CSS، JS، عکس‌ها، متن‌ها، تور ۳۶۰، sitemap، آدرس صفحه‌ها،
هدرهای امنیتی، و رابط کاربری پنل مدیریت.

**عوض شد:** فقط لایهٔ سرور —
- `_headers` و `_redirects` (مخصوص Netlify) → `.htaccess` / کانفیگ nginx
- `netlify/functions/admin.mjs` (Node) → `api/admin/index.php` (PHP، قرارداد API یکسان)
- دیپلوی خودکار Netlify → GitHub Action با آپلود FTPS

`.htaccess` و کانفیگ nginx **خودکار** از `_headers` و `properties.json` ساخته می‌شوند،
پس وقتی فایل جدیدی اضافه شود، آدرسش خودش به کانفیگ اضافه می‌گردد و هیچ‌وقت از هم جدا نمی‌افتند.
