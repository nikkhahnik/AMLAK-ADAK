# وب‌سایت املاک آداک

## انتشار
سایت روی Netlify میزبانی می‌شود. دامنه اصلی تنظیم‌شده در پروژه: `amlakadak.life` و نشانی جایگزین Netlify: `amlakadak.netlify.app`.

برای انتشار خودکار و فعال شدن پنل مدیریت، پروژه Netlify باید به مخزن GitHub زیر متصل باشد:
`nikkhahnik/AMLAK-ADAK` — شاخه `main`.

فایل `netlify.toml` ریشه انتشار را تنظیم می‌کند. پس از اتصال Git، هر commit روی شاخه اصلی یک انتشار تازه در Netlify ایجاد می‌کند.

## پنل مدیریت محتوا
پیکربندی پنل Pages CMS در فایل `.pages.yml` قرار دارد. مسیر `/admin/` صفحه ورود به پنل را نشان می‌دهد.

برای شروع:
1. در `/admin/` گزینه «ورود به پنل مدیریت» را انتخاب کنید.
2. در Pages CMS با حساب GitHub وارد شوید.
3. GitHub App مربوط به Pages CMS را فقط برای مخزن `nikkhahnik/AMLAK-ADAK` مجاز کنید.
4. مخزن و شاخه `main` را انتخاب کنید.
5. از بخش «صفحات وب‌سایت» فایل‌های HTML را ویرایش کنید؛ از بخش «طراحی و ظاهر» فایل‌های CSS و JavaScript در دسترس‌اند.
6. تصاویر تازه را در رسانه‌های سایت بارگذاری کنید. مسیر عمومی آن‌ها زیر `/assets/uploads/` خواهد بود.

Pages CMS تغییرات را در GitHub ثبت می‌کند. پس از اتصال خودکار مخزن به Netlify، انتشار سایت با هر commit انجام می‌شود. تا پیش از اتصال GitHub به Netlify، ذخیره در CMS به‌تنهایی نسخه زنده را به‌روز نمی‌کند.

## محدوده ویرایش
پنل فعلی دسترسی ویرایش فایل‌های HTML صفحات اصلی، ملک ۰۱۹، حریم خصوصی و QR را می‌دهد. همچنین CSS، JavaScript، تنظیمات مسیرها، robots.txt و هدرهای امنیتی در بخش فنی قابل ویرایش‌اند. این ویرایشگر برای تغییر ساختار و ظاهر کامل سایت هم دسترسی می‌دهد؛ تغییرات کد باید با دقت انجام شوند.

## حریم خصوصی
اطلاعات مالکان، شماره تماس مالکان، نشانی دقیق، قیمت توافقی، مدارک و یادداشت‌های داخلی در مخزن عمومی و صفحات وب‌سایت قرار نمی‌گیرند. اطلاعات کامل فایل‌ها و مالکان طبق تصمیم دفتر در پرونده‌های فیزیکی نگهداری می‌شوند. در محتوای عمومی فقط مشخصات غیرمحرمانه و تصاویر تأییدشده منتشر شود.

## صفحات عمومی
- `/` صفحه اصلی
- `/p/adk-019` صفحه اختصاصی فایل ۰۱۹
- `/privacy.html` حریم خصوصی
- `/qr.html` ساخت و چاپ QR

## توجه فنی
نسخه قدیمی `admin.html` به API سروری که در Netlify پیکربندی نشده بود متکی بود. پنل جدید از Pages CMS و GitHub برای مدیریت فایل‌های سایت استفاده می‌کند و به دیتابیس یا نگهداری آنلاین اطلاعات محرمانه نیاز ندارد.
